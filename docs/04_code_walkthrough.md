## Data flow

```
log_kvrh.json.gz ──featurize.py──> features.csv ──train.py──> results/ (metrics + plots)
                                         │
                                         └──app.py──> trains Gradient Boosting models ──> web UI
```

## `src/featurize.py`

| Part | Purpose |
|---|---|
| `ELEM_PROPS` | The 10 elemental properties, read from pymatgen's `Element` |
| `_elem_table()` | Builds a table of those properties for every element; fills the rare missing values with the column mean |
| `composition_features(composition)` | The 50 fraction-weighted statistics plus `n_elements`. Needs only a formula; also used by the app's formula tab |
| `featurize(struct_dict)` | Full descriptor set for one structure: composition statistics plus lattice, density, packing fraction and nearest-neighbour distances |
| `main()` | Loads the dataset, featurizes all structures in parallel with `joblib`, saves `features.csv` |

## `src/train.py`

1. Loads `features.csv` and splits it 80/20 (`random_state=42`).
2. Defines the four models. Linear Regression and MLP are wrapped in a `StandardScaler` pipeline because they are sensitive to feature scale; tree models are not.
3. For each model: 5-fold CV on the training set, fit on the full training set, predict on the test set, compute MAE / RMSE / R² / MAE in GPa.
4. Saves `metrics.csv` and `metrics.md`, then draws the parity plots, model comparison chart, feature importance chart and target histogram.

## `app.py`

| Part | Purpose |
|---|---|
| `load()` | Cached with `@st.cache_resource`, so it runs once. Uses the same 80/20 split, trains the structure-aware and composition-only Gradient Boosting models, and builds lookup tables of formulas and DFT values |
| `predict()` | Featurizes an uploaded structure and runs the structure-aware model |
| `structure_card()` | Shows formula, atom count, density, volume per atom and lattice |
| `stiffness_label()` | Turns GPa into a label: < 20 very soft, < 80 soft, < 180 moderately stiff, otherwise very stiff |
| Tabs | Predict from formula, Browse test materials, Upload your own CIF, Model performance |

## Reproducibility

- Every random step uses `SEED = 42` (split, CV folds, models), so re-running gives the same numbers.
- The app uses the same split as `train.py`, so the "test materials" shown in the app are exactly the ones evaluated in the results.
